# v0.4.1 — 25m 거리 보충과 출발·활주 분리

기준일: 2026-09-08 · 상태: 오프라인 실험, 실제 횟수 정확도 미검증

## 확인한 문제

사용자가 25m 풀에서 촬영했다고 보충했다. 기존 5.7~17.7초 구간의 시작은
다이빙 중이고 끝은 반대편 벽 부근이다. 해당 편도 거리 25m를 **사용자 진술**
(`user_reported`)로 반영했다. 정확한 이륙·터치 시점, 수면 영법 구간만의 거리는
독립 측정하지 않았으며 수영장 길이만으로 임의 부분 구간을 25m로 취급하지 않는다.

프레임 확인에서 8.0·8.5·9.0·9.5초에는 양팔을 뻗은 활주 자세가 보였고
10.0초에는 자유형 팔 젓기가 보였다. 기존 팔 후보 5.949·6.364·7.918·9.430초는
출발·활주 구간 안에 있었다. 관절 추정의 흔들림·입수 자세 변화가 팔 동작 후보로
들어가는 문제다. 5.7~9.5초를 어시스턴트 영상 검토에 따른 제외 구간으로 지정했다.
정확한 첫 스트로크 시점의 독립 이벤트 라벨을 만든 것은 아니다.

## 변경 내용

- `ArmExclusion`/`--arm-exclusions`: 선수 ID, 반개구간 `[시작, 종료)`, 이유와
  검토 출처를 입력한다. 다른 원본의 구간 파일은 SHA-256으로 차단한다.
- 평활화·보간·좌우 이벤트 병합 **전에** 제외 구간을 분리한다. 한 프레임보다 짧은
  제외 구간도 서로 떨어진 신호를 이어 붙이지 않는다.
- 팔만 제외한다. 발차기 관측, 전체 25m, 타임스탬프, 관절 가시성과 신호 공백은
  그대로 유지한다. 제외 구간과 관측 불가 구간을 같은 것으로 취급하지 않는다.
- 팔과 킥의 집계 대상 구간이 달라지므로 킥/팔 비율 검증은 보류한다.
- 출력에 `review_assisted`와 실제 구간 출처를 남긴다. 어시스턴트 구간 검토만으로는
  DPS를 제공하지 않는다. 사용자 검토가 있어도 관절 공백·가시성 검사를 통과해야 한다.
- 거리의 `user_reported` 출처를 추가해 실제 실측(`user_measured`)과 구분한다.

모델 가중치 재학습, 자동 구간 분류, 잠영 킥 종류 자동 전환은 이번 변경에 포함하지 않았다.

## 재현 및 QA

```powershell
python -m analysis_v2.cli .\video\이강해.mp4 --stroke freestyle `
  --pose-cache-in tmp/analysis_v2/runtime/local-freestyle-v04-poses.json.gz `
  --arm-exclusions tmp/analysis_v2/runtime/local-freestyle-arm-exclusions.json `
  --distance-segments tmp/analysis_v2/runtime/local-freestyle-distance-segments.json `
  --output tmp/analysis_v2/runtime/local-freestyle-v041-phase-dps.json
```

개인 영상·프레임·포즈·구간 입력 파일은 로컬에만 보관한다.
CI에서는 영상 없이 합성 포즈로 제외 전후 횟수, 발차기 보존, 다른 선수 격리,
신호 공백 우회 방지, 프레임 사이 구간 분리, 전 구간 제외의 미확정 처리,
DPS 부분 구간 재집계, 잘못된 입력·중복·원본 해시와 CLI를 검증한다.
기존 61개에 18개를 추가해 영상 회귀 테스트 79개, 전체 핵심 204개다.
