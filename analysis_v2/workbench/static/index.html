분석 조건

한 프로젝트에서 한 선수/레인을 검증합니다. 구간을 확정하면 같은 조건으로 수기 기록과 비교합니다.

수영장 길이와 부분 구간 이동 거리는 다릅니다. 모르면 거리는 비워두세요. 카메라 이동·재생 속도 변경·장면 전환이 있는 영상은 결과가 불안정할 수 있습니다.

내가 직접 센 동작

모델 답안 숨김

자유형·배영: 한 팔의 동작을 1회. 평영·접영: 양팔이 함께 하는 한 주기를 1회로 기록하세요. 같은 동작 지점을 일관되게 선택하세요.

자유형 교대 킥은 발 한 번, 동시 킥은 두 발이 함께 하는 한 주기입니다. 가려져 셀 수 없으면 ‘판독 불가’를 선택하세요.

기록한 시점

분석 조건 확정 후 A / K로 기록하세요.

모델 결과를 열면 이후 수정은 ‘보정용’으로 저장됩니다. 먼저 저장한 독립 기록은 따로 보존합니다.

모델이 찾은 동작 후보

버튼을 누르면 해당 장면으로 이동합니다. 후보가 실제 동작인지 확인해 주세요.

다시 볼 구간

관절 관측 공백·급격한 위치 변화입니다. 실제 가림인지 추적 오류인지는 영상으로 판단합니다.

교차 검증, 이렇게 해보세요

  1. 사용 권한이 있는 영상에서 한 선수/레인을 선택하고 분석 구간을 확정합니다.
  2. 저속 재생·프레임 이동으로 보면서 팔은 A, 킥은 K를 누릅니다. 판독 불가를 0회로 기록하지 마세요.
  3. 수기 기록을 저장한 뒤 모델 답안을 엽니다. 후보 시점을 눌러 차이를 확인합니다.
  4. ‘기록 내보내기’로 JSON과 비교 자료를 보관합니다. 다른 사람이 독립 검수하려면 같은 영상을 새로 올리고 답안을 보기 전에 기록해야 합니다.

이 도구는 실제 정확도 검증을 위한 실험실입니다. 가중치를 자동 학습하거나 서비스 훈련 일지에 저장하지 않습니다. 원본 영상·포즈·라벨은 로컬 작업 폴더에 남으며 ‘영상 삭제’로 함께 지울 수 있습니다.
