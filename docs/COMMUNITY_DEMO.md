# Community demo — 2026-10-24

An explicitly labelled read-only demonstration at `/community_demo`, linked from
the real community. Four fictional QA personas, six posts and eighteen comments
demonstrate questions, replies, follow-up and information sharing.

Dates in September/October are labelled scenario/example dates on every post and
comment, not actual creation timestamps. The page prominently states the real
fixture production date (2026-10-24) and that this is not real member activity.
Profiles include `[QA 데모]` in their names.

Fixtures are versioned in `frontend/static/community-demo.js`; no writes or reads
to the community/customer APIs occur. No QA login, account nickname, database row,
actual post timestamp, notification, like or real engagement counter is modified.
The page is noindex/nofollow. Search, category filters and expandable threads are
local, read-only interactions. This deliberately does not populate the real board
with fictional users or historical activity.
