# SwimMate 기능 지도

> 코드 기준일: 2026-08-03 · 기준 브랜치: `main`

이 문서는 “어떤 사용자가 어느 화면에서 무엇을 하고, 어떤 API와 데이터로 이어지는가”를 빠르게 확인하기 위한 지도다. 마케팅 설명이 아니라 현재 `api/main.py`, 등록 라우터, 프론트엔드 페이지와 QA 코드를 대조한 결과를 적는다.

## 역할과 접근 경계

| 역할 | 진입 방식 | 볼 수 있는 범위 |
| --- | --- | --- |
| 비회원 | `/login`, 공개 정보 페이지 | 로그인·가입·체험 진입, 훈련 플랜 둘러보기, 드릴·부상·장비·FAQ·릴리즈 노트·피드백 |
| 비회원 체험 사용자 | 로그인 화면의 `/auth/demo` | 격리된 샘플 계정으로 `/landing`, 대시보드, 일지, 리포트, 뱃지 등 회원 흐름 체험 |
| 일반 회원 | 로컬 또는 Google/Kakao 로그인 | 본인 훈련·커뮤니티·코치 연동, 참여한 클럽·반 데이터 |
| 등록 코치 | 일반 회원이 코치 프로필 등록 | 일반 회원 기능 + 연동 학생 조회·피드백·강습 운영·클럽·반 생성·Jira 운영판 |
| 선택 인증 코치 | 자격 정보 제출 후 관리자 확인 | 기능 권한은 등록 코치와 같고 학생 화면에 본인 확인 배지 표시 |
| 슈퍼 관리자 | `role='admin'` 또는 `ADMIN_ID` 호환 계정 | 운영 집계, 사용자·코치·피드백·페이지 조회·운영 로그 |

코치 권한은 관리자 승인 대기 상태와 무관하다. 등록 즉시 코치 코드가 발급되며, 학생이 직접 코드를 입력해 활성 관계를 만들어야 학생 기록에 접근할 수 있다.

## 개인 훈련 데이터 흐름

1. 로그인 후 `/landing`으로 이동한다. 설정이 미완료라면 랜딩 안내에서 수준·목표·주간 횟수·선호 풀을 저장하고, 완료된 설정은 프로필에서 다시 수정한다.
2. 대시보드 어드바이저와 플랜 생성 폼이 같은 설정을 추천 거리·목표 세트·풀 길이·난이도 기본값으로 사용한다.
3. 사용자가 대시보드 준비도를 저장하거나 플랜을 선택한다.
4. 일지를 직접 작성하거나 플랜에서 세트가 포함된 일지를 만든 뒤 풀사이드 실행 화면을 연다.
5. 출발 사이클 또는 스톱워치로 반복을 진행하고 실제 횟수·거리·평균 사이클·RPE·상태·메모를 한 세트씩 저장한다.
6. 일지의 총거리·시간은 `training_logs`, 반복·거리·사이클·완료량은 소유권이 같은 `training_log_sets`에 순서대로 저장된다.
7. 단일 세트 저장과 같은 트랜잭션에서 실제 완료 거리 합계가 일지 총거리에 반영된다.
8. `training_logs`가 대시보드, 월간 리포트, 뱃지와 챌린지의 공통 기준 데이터가 되고, 세트 데이터는 일지와 리포트의 수행률을 보완한다.
9. 플랜에서 생성한 일지는 `plan_completions`와 연결되어 리포트의 플랜 완료 세션·거리·사이클 포함률에 반영된다.
10. 월간 목표는 `training_goals`에 저장되고 일지와 리포트에서 같은 고객 ID로 집계된다.
11. 테스트 세트는 `swim_test_results`에 0.01초 단위로 저장되며, 영법·거리·풀 길이가 같은 기록끼리만 PB를 비교한다.
12. 테스트 기록을 일지에 연결할 때는 같은 소유자·날짜·풀 길이를 검사하고, 월간 리포트는 해당 월 시도·신규 PB와 전체 현재 최고기록을 함께 집계한다.
13. `/my-data`는 같은 고객 ID의 전체 기록을 평생 누적·최근 90일·12개월·영법·풀·기록 습관·코스별 PB로 다시 읽어 장기 변화와 다음 행동을 설명한다. JSON 내보내기는 백업·이동용 원본 역할을 유지한다.

건강 데이터 가져오기는 현재 공개 화면에서 비활성 상태다.

- 훈련 일지의 `워치 데이터 가져오기 (준비 중)` 버튼은 `disabled`와 `aria-disabled`를 사용하며 모달 열기 이벤트를 연결하지 않는다.
- `/api/training-log/import/*`와 파서 코드는 향후 재검증을 위해 남아 있지만 현재 사용자 기능으로 소개하지 않는다.
- Apple Watch·Galaxy Watch 직접 동기화와 Health Auto Export·Apple 건강·Samsung Health 파일 가져오기를 현재 제공 기능으로 약속하지 않는다.

## 코치·수강생 기능

### 클럽·반 그룹 구조

1. 등록 코치가 클럽을 만들면 클럽 소유자 멤버십이 함께 생성된다.
2. 클럽 소유자나 클럽 코치는 수준·목표·풀 길이·정원을 정해 반을 만들고 `LANE-XXXXXX` 참여 코드를 받는다.
3. 학생이 반 코드를 입력하면 클럽 `member`와 반 `student` 멤버십이 같은 트랜잭션에서 생성된다.
4. 클럽 역할(`owner`, `coach`, `assistant`, `member`)과 반 역할(`coach`, `assistant`, `student`)은 범위별로 분리한다.
5. 코치·보조 코치 역할은 `coaches`에 등록된 회원에게만 부여하며, 반 코치는 클럽 전체가 아닌 지정된 반만 관리할 수 있다.
6. 정원, 담당 코치 강등·이탈, 다른 클럽·반 접근을 API에서 다시 검사한다.
7. 클럽 운영자 또는 해당 반 코치가 수업 일정을 등록하고 학생 명단에 출석 상태를 기록한다.
8. 클럽 전체·반 공지는 대상 회원에게 알림으로 전달되며 사용자별 읽음 상태를 따로 저장한다.
9. 반 운영자는 확인된 출석률과 기록 완료율을 분리해 보고 주간 추이와 학생별 확인 필요 신호를 확인한다.
10. 개인 훈련 횟수·거리는 반 멤버십이 아니라 현재 `coach_students` 활성 관계가 별도로 있는 담당 코치에게만 표시한다.

### 학생이 보는 기능

- 코치 코드 입력, 새 코드로 관계 교체, 직접 연동 해제
- 코치 프로필과 선택 인증 상태 확인
- 코치 피드백·개별 플랜·강습 일지·강습표·일정표 수신
- 참여한 반의 일정·공지를 확인하고 본인 출석 상태만 조회
- 오늘 자유수영 내용을 코치에게 공유

### 코치가 보는 기능

- 등록 즉시 `SWIM-XXXX` 코치 코드 발급·복사·기기 공유
- 선택 자격정보 제출과 상태 확인
- 연동 학생 목록, 최근 일지, 자유수영 공유, 피드백과 개별 플랜
- 전체 학생 대상 강습 일지
- AI 또는 규칙 템플릿 기반 단체 강습표·과정 일정표 생성
- 코치 검토·수정 후 전체 또는 선택 학생 배포
- 학생 실명 대신 `S1`, `S2`를 Gemini에 보내는 익명 수업 브리핑
- 최근 30일 훈련·준비도 신호 기반 크루 운영판
- 코칭 과제 로컬 저장, Jira 동기화·분석·완료 처리
- 담당 반 일정·출석·공지를 운영하고 공지 읽음 인원 확인
- 담당 반의 주간 출석 추이와 학생별 수행 신호 확인. 개인 훈련량은 코치 코드 연동 학생만 조회

Jira가 설정되지 않거나 호출에 실패해도 코칭 과제는 SwimMate DB에 먼저 남는다. Jira 웹훅은 `JIRA_WEBHOOK_SECRET` HMAC 서명을 검증한 뒤 상태를 갱신한다.

## 관리자 기능

모든 주요 목록은 20·50·100개 표시와 번호 페이지 이동을 지원한다. 사용자·코치·운영 로그·피드백은 전체 또는 필드별 검색을 서버 페이지네이션과 함께 적용한다.

| 탭·영역 | 확인 항목 |
| --- | --- |
| 운영 요약 | 7/30/90일 페이지 조회·추정 순 방문자·로그인 회원·신규 가입 추이 그래프, 가입 방식 분포 |
| 사용자 | ID·이름·이메일·아이디·닉네임·가입 방식·상태 검색, 최근 로그인, 페이지 크기·페이지 이동 |
| 코치 운영 | 이름·아이디·이메일·전문 분야·경력·자격 정보 검색, 등록·미인증·인증 대기·완료·반려, 최근 AI 문서·배포 |
| 훈련 운영 | 30일 일지·활성 사용자·거리·평균, 목표·플랜 완료, 준비도, 테스트 참여 사용자·테스트 기록·PB, 영법·풀 길이, 활성 클럽·반, 30일 반 일정·출석률·공지 |
| 피드백 | 유형 필터, 작성자·페이지·제목·내용·이메일 검색, 작성자 닉네임·계정 정보와 내용 |
| 운영 로그 | 페이지 조회 포함 이벤트 유형 필터, 아이디·경로·동작·HTTP 방식·IP 검색, 페이지 크기·페이지 이동 |

관리자 QA는 운영 데이터 변경을 피하기 위해 조회·탭·필터 중심으로 실행한다.

## AI 코치 지식·개인화 흐름

1. 최근 사용자 발화 최대 3개를 묶어 후속 질문의 실제 주제를 만든다.
2. 키워드 점수로 영법·사이클·풀 길이·장비·안전·위생·규정·회복 중 관련된 검수 지식 최대 3개를 선택한다.
3. `내 기록`, `최근 훈련`, `맞춤 추천`처럼 명시적인 개인화 의도가 있을 때만 로그인 사용자의 훈련 설정·최근 일지 수치·주간/월간 요약·목표·준비도·PB·플랜/세트 수행 요약을 읽는다.
4. 이름·이메일·사용자명·일지 메모·준비도 자유 메모를 제외한 문맥을 Gemini에 전달한다.
5. 답변에는 선택된 지식 분야, 공식 출처, 관련 내부 가이드와 개인 기록 반영 여부를 함께 반환한다.
6. 경기 규정은 `최신 확인 필요`로 표시하고 World Aquatics 원문과 참가 대회 요강을 다시 확인하도록 안내한다.
