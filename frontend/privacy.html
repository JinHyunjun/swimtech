5. 이용자의 권리

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

  • 열람: 본인의 개인정보 열람 요청
  • 정정: 부정확한 개인정보 정정 요청
  • 삭제: 개인정보 삭제 요청 (회원 탈퇴)
  • 처리 정지: 개인정보 처리 정지 요청
  • 이동: 프로필의 내 데이터 내보내기에서 계정·훈련·테스트 기록·플랜·활동 데이터를 JSON 파일로 다운로드

내보내기 파일에는 비밀번호 해시, 로그인 토큰, 소셜 제공자 식별자, 외부 서비스 비밀값과 다른 회원의 계정 프로필을 포함하지 않습니다. 로컬 계정은 파일 생성 전에 현재 비밀번호를 다시 확인합니다.

그 밖의 권리 행사는 서비스 내 설정 메뉴 또는 이메일(hyeonjunj014@gmail.com)로 요청하실 수 있습니다.

6. 개인정보 보호를 위한 기술적 조치
  • 비밀번호 bcrypt 단방향 암호화 저장
  • JWT HttpOnly 쿠키 (8시간 만료)
  • 계정별 세션 버전을 확인해 비밀번호 변경·전체 로그아웃·회원 탈퇴 후 기존 액세스·갱신 토큰 무효화
  • 개인 데이터 내보내기와 계정 보안 변경 전 로컬 계정의 현재 비밀번호 재확인
  • 회원 탈퇴 요청의 확인 문구와 로컬 계정 현재 비밀번호를 서버에서 재검증
  • HTTPS 통신 암호화 (Vercel·Render 운영 환경, 로컬 Caddy)
  • Redis가 연결된 환경에서 동일 IP 로그인 5회 실패 시 15분 잠금
  • 로그인·체험 로그인·AI 요청별 Rate Limiting
  • 파일 업로드 유형 및 크기 검증
