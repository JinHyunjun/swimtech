50m 경기 · 분석할 선수 확인

레인 번호는 화면 위아래 순서가 아닌 실제 경기 레인입니다. 번호만으로 선수를 찾지 않습니다. 시작 장면에서 해당 선수를 직접 클릭해 연결하세요.

카메라와 선수의 움직임에 따라 탐색 위치·크기를 바꾸며 여러 검출 후보 중 선택 선수를 추적합니다. 장면 전환·겹침 이후에는 해당 시점으로 이동해 같은 선수를 다시 클릭하여 확인점을 추가할 수 있습니다. 구분이 불확실한 구간은 집계를 보류하며 다른 선수로 자동 교체하지 않습니다.

50m 경기라도 일부 구간만 선택하면 해당 구간만 집계합니다. 가려진 킥을 추측하거나 전체 경기 횟수로 환산하지 않습니다. 거리도 자동으로 50m를 입력하지 않습니다.

추적 확인점은 분석 완료 후 수정할 수 있습니다. 단, 수기 기록을 저장한 조건은 검수 일관성을 위해 변경할 수 없습니다.

모델 답안 숨김

자유형·배영: 한 팔의 동작을 1회. 평영·접영: 양팔이 함께 하는 한 주기를 1회로 기록하세요. 같은 동작 지점을 일관되게 선택하세요.

자유형 교대 킥은 발 한 번, 동시 킥은 두 발이 함께 하는 한 주기입니다. 가려져 셀 수 없으면 ‘판독 불가’를 선택하세요.

교차 검증, 이렇게 해보세요

  1. 사용 권한이 있는 영상에서 한 선수/레인을 선택하고 분석 구간을 확정합니다.
  2. 저속 재생·프레임 이동으로 보면서 팔은 A, 킥은 K를 누릅니다. 판독 불가를 0회로 기록하지 마세요.
  3. 수기 기록을 저장한 뒤 모델 답안을 엽니다. 후보 시점을 눌러 차이를 확인합니다.
  4. ‘기록 내보내기’로 JSON과 비교 자료를 보관합니다. 다른 사람이 독립 검수하려면 같은 영상을 새로 올리고 답안을 보기 전에 기록해야 합니다.
