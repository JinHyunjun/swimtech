SWIMMATE START GUIDE

기능이 많아도,
순서는 간단해요

SwimMate는 기능을 따로 쓰는 도구가 아니라 설정한 기준으로 훈련을 고르고, 실제 수행을 기록한 뒤, 성장과 다음 행동을 확인하는 하나의 흐름입니다. 아래 실제 화면을 따라 필요한 기능부터 시작해 보세요.

개인 훈련 흐름부터 보기 코치·클럽 기능 보기 전체 메뉴로 돌아가기
PATH 01

혼자 훈련한다면

맞춤 설정 → 준비도 → 플랜 → 풀사이드 실행 → 일지 → 리포트 순서로 시작하세요.
PATH 02

코치·클럽이라면

코치 코드로 연결한 뒤 반, 일정, 출석, 공지와 단체 강습 자료를 운영하세요.
PATH 03

먼저 둘러본다면

비회원 체험으로 샘플 데이터와 주요 화면을 확인하고 커뮤니티·정보 기능을 살펴보세요.
개인 훈련 실행·기록 성장 확인 코치·클럽 탐색·정보 기능 찾기
01 · PREPARE & PLAN

내 기준을 정하고
오늘 훈련을 고르기

처음에는 세 가지 기능만 기억하면 됩니다. 맞춤 훈련 설정은 추천의 기준, 대시보드는 오늘의 판단, 훈련 플랜은 실제로 수행할 세트입니다.

로그인 필요처음 1회 설정

맞춤 훈련 설정

현재 수준, 주요 목표, 주당 횟수와 25m·50m 선호 풀을 저장합니다. 이 값은 대시보드 추천과 플랜 기본값에 함께 반영됩니다.

  • 처음 로그인했거나 훈련 환경이 바뀌었을 때 사용
  • 프로필에서 언제든 기존 설정을 다시 수정
설정 시작하기현재 설정 확인
로그인 필요매 훈련 전

훈련 대시보드

주간 목표와 최근 훈련을 확인하고 수면·피로·근육 상태·가능 시간을 입력합니다. 설명 가능한 규칙으로 오늘의 준비도와 다음 세션을 추천합니다.

  • 컨디션이 좋지 않을 때 회복·기술 세션으로 조정
  • 추천 카드에서 플랜·일지·월간 리포트로 바로 이동
오늘 상태 확인
둘러보기 공개저장은 로그인 필요

훈련 플랜

기록 단축·건강·영법 교정·취미 등의 목적, 25m·50m 수영장, 수준별 사이클과 드릴·대시 비중을 선택합니다. 준비된 플랜을 고르거나 세트를 직접 구성할 수 있습니다.

  • 세부 세트마다 거리·반복·목표 출발 사이클을 확인
  • 저장 전 총거리·강도·휴식·세션 구성을 품질 점검
  • 실제 수행할 플랜을 일지로 보내 구조화된 세트로 저장
플랜 둘러보기직접 구성하기
02 · EXECUTE & RECORD

수영장에서는 실행하고
끝난 뒤 실제로 기록하기

플랜은 계획이고 일지는 실제 수행입니다. 세트가 있는 일지를 만들면 풀사이드 화면에서 반복을 진행하고 수행 결과를 그대로 저장할 수 있습니다.

로그인 필요기준 데이터

훈련 일지와 테스트 세트

영법·거리·시간·강도·기분·풀 길이를 기록합니다. 플랜을 가져오면 목표 세트와 사이클도 함께 저장되며, 테스트 기록은 영법·거리·25m/50m 코스별 PB로 분리됩니다.

  • 월간 목표·캘린더·총거리·평균거리·연속 출석 확인
  • 건강 앱에서 내보낸 파일은 미리보기 후 선택 가져오기
일지 기록하기
세트 일지 필요수영장용

풀사이드 훈련 실행

큰 글씨로 현재·다음 세트와 거리 진행률을 보고 출발 사이클 카운트다운 또는 스톱워치로 반복을 진행합니다.

  • 반복 완료·건너뛰기·이전·다음과 화면 켜짐 유지
  • 실제 거리·사이클·RPE·상태를 세트별로 저장
  • 저장된 완료 거리가 일지 총거리와 리포트에 즉시 반영
실행할 일지 선택
03 · REVIEW & IMPROVE

한 달의 결과와
전체 성장 흐름을 나눠 보기

월간 리포트는 선택한 한 달의 상세 성과를, 내 수영 데이터는 전체 기간과 최근 90일·12개월 변화의 맥락을 보여줍니다.

훈련 일지무엇을 했나

개별 세션과 세트의 실제 수행을 저장하는 원본입니다.

월간 리포트이번 달 어땠나

한 달의 거리·빈도·수행률과 PB를 비교합니다.

내 수영 데이터장기적으로 어떤가

전체 이력·12개월·기록 습관과 다음 행동을 해석합니다.

로그인 필요월별 분석

월간 성장 리포트

훈련 일지를 기준으로 거리·횟수·평균·시간·영법·주차·요일을 집계하고 전월 대비 성장률을 계산합니다.

  • 플랜·사이클·구조화 세트 수행률과 월간 목표 달성률
  • 해당 월 테스트 시도·신규 PB와 현재 코스별 PB
이번 달 확인

  • 세트·플랜·실제 사이클을 얼마나 기록했는지 확인

04 · COACH & GROUP

개인 운동과 분리된
코치·클럽 운영 공간

일반 사용자의 개인 플랜과 달리 코치는 여러 학생에게 배포할 강습 자료와 반 운영 업무를 관리합니다. 코치 등록 즉시 코드를 받고, 학생이 코드를 입력한 관계에서만 개인 기록을 확인합니다.

로그인 필요등록 코치

코치 연결과 클럽·반

코치는 `SWIM-XXXX` 코드를 학생에게 공유하고, 클럽과 수준·목표·풀 길이·정원을 가진 반을 만듭니다. 학생은 `LANE-XXXXXX` 반 코드로 직접 참여합니다.

  • 코치·보조 코치·학생 역할을 클럽과 반 범위로 분리
  • 학생이 허용한 코치만 개인 일지·피드백·플랜에 접근
코치 연동클럽·반 보기

  • AI로 단체 훈련표·강의 일정표·익명 수업 브리핑 초안 생성
